# Catálogo e dicionário por fonte

**129 fontes, produtos ou coleções. Consulta em 2026-09-14.**

Cada ficha informa o conteúdo de interesse, o acesso, o custo em termos gerais, a cobertura, as limitações e uma referência direta. Os campos ligados ao dicionário normalizado são **alvos conceituais de integração**, não campos nativos garantidos. As fichas com evidência parcial ou pendente estão explicitamente marcadas.

A unidade de contagem é um produto/fonte ou coleção utilizável: uma empresa pode ter uma oferta comercial e uma amostra aberta, que aparecem separadamente. As 129 entradas não são 129 fornecedores independentes nem 129 APIs. Mirrors e bibliotecas não foram multiplicados para aumentar a contagem.

### 001. Big Balls Sports Data

- **Categoria:** APIs de futebol.
- **Acesso:** API documentada; cliente pitchside já usado no projeto.
- **Custo:** Freemium.
- **Cobertura:** Ligas de futebol disponíveis no plano; projeto usa EPL.
- **Conteúdo a explorar:** Placar; calendário; elenco; estatísticas; confrontos; odds conforme plano.
- **Dicionário conceitual das entidades:** [partida](dicionario-normalizado.md#partida), [equipe](dicionario-normalizado.md#equipe), [jogador](dicionario-normalizado.md#jogador), [estatistica](dicionario-normalizado.md#estatistica), [odd](dicionario-normalizado.md#odd), [clima](dicionario-normalizado.md#clima).
- **Limites e atualização:** A página pública mistura recursos disponíveis e roadmap; conferir cobertura por liga e endpoint. O SQL local registra colunas vazias na captura histórica.
- **Verificação:** Documentação pública consultada. Sem teste autenticado de integração nesta pesquisa.
- **Referência:** [fonte/documentação](https://bigballsdata.com/docs).
